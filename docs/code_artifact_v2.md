**项目名称**：「延边朝鲜族民俗村·乡村振兴」三维数字场景设计与实现

## 一、设计立意与核心命题融合

本作品以 **"数字光影里的延边民俗村：金秋晨曦中的振兴画卷"** 为核心主题，在 $200 \times 200$ 单位的三维场景中融合三大精神面貌元素：

1. **延边特色（人文核心）**：以白墙、青灰瓦、飞檐如鹤翼上扬的**朝鲜族歇山式瓦顶民居**为视觉中心，配以朝鲜族民居特有的**屋旁独立烟囱**（与火炕结构相连）、百年老树下的民俗秋千、跳板、石砌老水井，以及中朝双语（中文 / 한글）欢迎门楼。
2. **乡村振兴（产业风貌）**：中景布置随风起伏的金色稻田、现代风力发电机组与太阳能光伏板阵列，展现传统民俗村向生态富裕新农村的蜕变。
3. **旅游城市（互动导览）**：设置中朝双语导览牌、沿 B 样条路线行驶的**观光小火车/游览车**、门楼牌匾上的延吉城市天际线剪影，并提供基于 B 样条曲线的自动导览视角。

### 季节设定（统一逻辑）
* **默认季节：金秋**——金色稻田 + 晨间炊烟 + 远山红叶，为全片主视觉。
* **切换季节：初冬瑞雪**（按 `O`）——稻田变为收割后的浅褐色茬地，粒子由炊烟切换为雪花，屋顶与地面叠加积雪色调。
* 金达莱作为**延边州花元素**以彩绘图案形式出现在门楼与导览牌上，不再作为季节性花丛种植，避免季节矛盾。

### 2. Uber-Shader 关键 Uniform
| Uniform | 取值 | 作用 |
| :--- | :--- | :--- |
| `u_ShadeMode` | 0 Flat / 1 Gouraud / 2 Phong | 明暗处理切换 |
| `u_AnimType` | 0 无 / 1 水波 / 2 稻浪 | 顶点动画 |
| `u_IsShadowPass` | bool | 输出半透明冷色阴影 |
| `u_UseEnvMap` | bool | 水面采样 Cubemap 反射 |
| `u_PointLights[8]`, `u_NumPointLights` | 最多 8 盏 | 夜间点光源（村口 4 + 门楼 2） |
| `u_FogColor`, `u_FogDensity` | 随状态插值 | 距离 + 高度雾 |

**三种着色的实现要点**：
* **Flat**：顶点着色器输出 `flat out vec3 v_Color`（取激发顶点的光照），或片元中用 `normalize(cross(dFdx(pos), dFdy(pos)))` 求面法线。
* **Gouraud**：顶点阶段计算 Blinn-Phong，输出颜色做线性插值。
* **Phong**：插值法线与世界坐标，片元阶段逐像素计算。
* 片元末尾统一做伽马校正：`color = pow(color, vec3(1.0/2.2))`（贴图以 `GL_SRGB8_ALPHA8` 格式加载，保证线性空间计算）。

### 3. 单帧渲染管线（5 Passes）
1. **Pass 1：CPU 更新**
   * 计算 $\Delta t$，更新风车角、秋千简谐摆角 $\theta(t) = \theta_0 \sin(\omega t)$、观光车位置、B 样条相机、光照状态插值、粒子。
   * 沙盘数据变化时，CPU 执行光栅化 / 裁剪算法并 `glTexSubImage2D` 刷新纹理。
2. **Pass 2：天空盒（深度测试关闭时）**
   * 若用户按 `Z` 关闭深度测试，**先**绘制天空盒作为背景（关闭深度写入），避免其覆盖场景。
3. **Pass 3：不透明几何体**
   * 开启深度测试（受 `Z` 键控制），绑定 `uber_scene`，传入 $P, V$、平行光与点光源数组。
   * 绘制顺序：地形 → 稻田（实例化，剔除后上传可见实例）→ 民居 → 风车/秋千/车 → 水面（开启 `u_UseEnvMap`）。
4. **Pass 4：平面阴影 + 天空盒（正常模式）**
   * **阴影**：仅在状态 1、2 执行。根据平行光方向（$w=0$）与地面平面 $y = 0.01$ 构建 $M_{shadow}$；开启模板测试（每像素只绘制一次，防止叠加变黑）+ Alpha 混合，输出 `rgba(0.15, 0.18, 0.28, 0.45)` 冷色半透明阴影。阴影只投射在村落平坦区域（$R < 35$）。
   * **天空盒**：深度函数设为 `GL_LEQUAL`，移除视图矩阵平移分量，`gl_Position = pos.xyww` 使深度恒为 1.0。
5. **Pass 5：半透明物体**
   * 开启 `GL_BLEND`，`glDepthMask(GL_FALSE)`；将双语牌匾与粒子按到相机距离**统一由远及近排序**后绘制；恢复深度写入并交换缓冲区。

## 五、视觉设计规范（Art Direction）

### 1. 风格定位
**低多边形风格化**：以程序化生成的简洁几何体为主，面片清晰、色块明确；贴图只用于少量需要细节的部位（瓦片纹理、牌匾文字、木纹），其余用顶点色 / 纯色材质。这样程序化建模和贴图的风格才能统一，不会显得廉价、拼凑。

### 2. 统一调色板
| 用途 | 色值 | 说明 |
| :--- | :--- | :--- |
| 民居白墙 | `#F2EFE8` | 暖白，非纯白，避免过曝 |
| 青灰瓦顶 | `#4A5560` | 朝鲜族传统瓦色 |
| 木框门窗 | `#5B3A29` | 深褐，勾勒建筑轮廓 |
| 石砌台基 / 水井 | `#9A958C` | 中性灰 |
| 金秋稻田 | `#D9A441` → `#E8C26A` | 顶点按高度渐变，模拟稻穗 |
| 金达莱彩绘 | `#E07AA0` | 仅作为点缀色 |
| 远山 | `#6E7F8F` → 雾色 | 由雾自然过渡 |
| 风车 / 光伏 | `#E6E9EC` / `#2B3A55` | 现代感冷色，与传统暖色形成对比 |

### 3. 民居造型要点（辨识度来源）
* 屋脊两端明显上翘，飞檐四角起翘（Bézier 控制点抬升）。
* 白墙下有一圈石砌台基；墙面用深色木框分隔，门窗采用格栅（细长立方体阵列）。
* **独立烟囱**立在屋侧，是炊烟粒子的发射点。
* 门楼牌匾：上中文"延边欢迎您"，下한글"연변에 오신 것을 환영합니다"，两侧彩绘金达莱。

### 4. 光影氛围
* 阴影使用**冷色半透明**，不用纯黑，以衬托暖色阳光。
* 晨曦状态加强雾效，远山呈层次化剪影；夜间点光源用暖黄 `#FFC870`，与月光冷蓝形成冷暖对比。
* 天空盒、雾色、环境光三者在每个状态下保持色调一致。

### 5. 主视角构图（用于封面与视频开头）
| 机位 | 构图 | 状态 |
| :--- | :--- | :--- |
| **A 主视觉** | 低角度仰拍民居飞檐，背景是晨光中的风车与远山 | 晨曦 |
| **B 全景** | 正交鸟瞰，展示三层同心圆布局 | 正午 |

## 七、3000 字《课程设计报告书》章节分配

1. **第 1 章 绪论与设计立意（约 400 字）**：延边朝鲜族民俗文化（歇山式民居、独立烟囱与火炕）、乡村振兴背景、三层同心圆空间规划、视觉风格定位。
2. **第 2 章 系统总体架构（约 500 字）**：渲染管线流程图、模块树、课程章节映射表。
3. **第 3 章 核心算法设计与实现（约 1650 字）**：
   * **3.1 二维光栅化与裁剪**：Bresenham 误差递推、扫描线 AET 填充、Cohen-Sutherland 区域编码。
   * **3.2 飞檐的多片 Bézier 曲面**：$P(u,v) = \sum_{i=0}^{3}\sum_{j=0}^{3} B_{i,3}(u)B_{j,3}(v)P_{i,j}$，法线 $n = \frac{\partial P}{\partial u} \times \frac{\partial P}{\partial v}$，以及相邻片 C¹ 连续条件（拼接边两侧控制点共线且等距）。
   * **3.3 层级建模与 B 样条相机**：矩阵栈推导、三次 B 样条基矩阵、Clamped 端点处理。
   * **3.4 光照、着色与阴影**：Blinn-Phong 方程、衰减公式、三种着色差异、平面投影矩阵推导、伽马校正。
4. **第 4 章 运行效果与对比分析（约 300 字）**：线框 / 实体、三种着色、昼夜三态、开关 Z-Buffer、细分精度 5 组对比图。
5. **第 5 章 问题排查与总结（约 150 字）**：阴影 Z-fighting（高度偏移）、非均匀缩放下的法线逆转置修正、Bézier 拼接缝法线不连续、关闭深度测试时天空盒覆盖场景。
